The manual compact WORKS server-side: session_message seq 64981, type compaction, status completed, reason manual at 12:40:13.851Z, summary created - proven from opencode.db, and the model runs on that summary. But the Eclipse chat shows only the transient notice. (1) Live: the event stream handles session.text.delta and session.reasoning.delta only, so the compaction message appends nothing to the open chat. (2) History: ChatEntryDeserializer.parts reads content or text only - a compaction row carries NEITHER, it carries summary/status/reason, so entry.text is empty and historyRows demotes it to role assistant, an empty bubble. (3) No test covers compaction parsing. Fix per the deserializer's own documented contract: reduce compaction to a readable marker text (completed with reason and timestamp, failed with error type and message), render it as a persistent visible transcript marker instead of an empty assistant bubble, and cover it with a regression test on the real wire shape.
