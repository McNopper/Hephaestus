T-258's review follow-up (2026-11-27), reproduced: running releng\lint.ps1 while the reactor runs -> Invoke-ScriptAnalyzer -Path $repo -Recurse churns over eclipse/**/target/ files being written/deleted by the build, fails with 'Unable to find the specified file' and exit 1 WITHOUT reporting findings - a false-red lint gate (the reviewer hit this mid-review and re-ran after the build settled). Lint must be deterministic: exclude target/ (and any build-output dirs the analyzer already shouldn't see) from the analyzer path so the result depends only on source.
