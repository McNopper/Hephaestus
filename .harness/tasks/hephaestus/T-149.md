Implements the owner's examples from 2026-11-16 ('we want to have the same in Eclipse e.g. context window, current goal and so on'; chat = the TUI/GUI surface). All wire contracts PROVEN live 2026-11-16 against the local 2.3.0 service: (1) goal RPC POST /api/rpc/opencode.goal/get {input:{sessionID}} -> {output: Goal.State|null} (this session returned the active objective; server without the plugin answers an error -> tolerate as no goal, per TUI goal.tsx); (2) live event rpc.opencode.goal.changed {sessionID, goal} arrives on /api/event (captured twice: set -> active, pause -> paused+reason), SSE stream has NO type filter (OpencodeEventStream); (3) session.usage.updated {sessionID, cost, tokens} carries live cost (proven 8x in capture); (4) GET /api/session/{sid} returns Session with cost+tokens (client lacks a single-session getter - add); (5) goal actions = POST /api/session/{sid}/command {name:'goal', text:'pause|resume|clear'} -> 204 (proven; MUST NOT reuse runCommand - its awaitCommandReply polls up to PROMPT_TIMEOUT 60min for an assistant reply that never comes; add a fire-and-forget verb); (6) context math ported from TUI util/session.ts: lastAssistantWithUsage (last assistant with tokens after last completed compaction; tokens = input+output+reasoning+cache.read+cache.write; percent = round(tokens/limit.context)) - model limit context=1048576 verified live; (7) goal-set creates a synthetic message {type:synthetic, metadata:{source:goal, goalID}, text:<full prompt>, description:'Goal: <objective>'} which today renders as a FULL assistant bubble with the whole untrusted_objective prompt (ChatEntryDeserializer parts() picks up text) - TUI renders a compact notice row (SessionNoticeMessage: icon + description). Placement: #status strip pinned at the chat page bottom, directly above the host input row (the chat's composer boundary; NFR-UX-001 existing-surface rule), mirroring the TUI prompt footer. T-141's store-sprint-goal placeholder stays (harness extra).
