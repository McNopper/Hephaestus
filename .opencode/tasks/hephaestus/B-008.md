Live 2026-09-20 (wave run): ten workers aborted with 'stalled: session idle and silent for PT5M' - the primary trigger was the missing task_* tools spiral (fixed: worktree-aware launchers), but the detector itself needs a second look: (1) a worker in a long silent MODEL/API phase (rate-limited provider, huge prompt, hung HTTP with no stream deltas) reads as 'idle and silent' and dies without any diagnostic of what it was waiting on - the abort should record the last observed state (last tool call, pending request age) so the next triage distinguishes model-hang from tool-hang from true-hang; (2) U-024 was killed by the PT30M ticket budget while busy:true with 50 messages and active test work - a budget that resets (or extends) on observed progress would not kill healthy long runs; the watchdog should abort on NO-progress, never on progress. Pairs with B-004 (timeout path leaks the serve).
