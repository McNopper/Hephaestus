User direction 2026-09-16 (live dogfooding): "when the fleet is running, I see the entry in the tab - however I want to see what is going on in detail, like seeing the current messages."

Implementation pointers (recon 2026-09-16):
- Open the details view exactly like ServerView.openSessionDetails: getSite().getPage().showView("com.opencode.ide.ui.views.SessionDetailsView", sessionId.replace('%','_'), IWorkbenchPage.VIEW_ACTIVATE) - the view id is a plain string, no bundle dependency needed; SessionDetailsView has allowMultiple=true and an Auto Refresh toggle already.
- The fleet worker session IS reachable through the primary client: FleetView.openDiff already does OpencodeConnection.getInstance().getClient().getSessionDiff(sessionId, null) (DiffSource.SERVER when the job has a sessionId) - the same client serves GET /session/:id/message for the details view.
- Enablement mirrors openDiffAction/takeOverAction (setEnabled(false) until a row with sessionId is selected); toolbar + fillContextMenu entry; double-click hook on the viewer.
- Icon: extend eclipse/bundles/com.opencode.ide.core/generate-action-icons.py with a "watch" (eye) glyph, run it, wire via the view's icon() helper.
