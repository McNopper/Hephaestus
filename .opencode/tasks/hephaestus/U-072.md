Owner direction 2026-10-07: beside skills and agents, the user can also wire SPECIFIC MODELS for specific V-stages - 'which model and setting should be used for which stage in general'. DispatchPolicyStore gains a stage_models map (VStage -> provider/model#variant, empty default = today's behavior everywhere). Resolution at dispatch time: explicit ticket.model wins (per-ticket escape hatch) -> stage policy -> server default. Every dispatch host consults the resolution (TaskFleet launcher, Board Launch task, auto-dispatch, recurring waves - one choke-point helper preferred). AGENTS.md's model-selection paragraph documents the precedence. Pairs with the settings-dialog ticket (per-stage pickers).
