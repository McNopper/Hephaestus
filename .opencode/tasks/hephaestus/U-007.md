User direction 2026-09-15 (wave-1 wrap-up): "in the gui, if an agent is working, on the session, this should be visible." Today the busy state of a session (chat reply streaming, fleet worker running) is not surfaced in the Session/Server view - the ui bundle already ships session.png and session-busy.png icons, so the visual language exists but the live state does not. Source of truth: the opencode server's session status (busy map; the same signal the fleet watchdog uses). Pairs with U-003 (chat-side thinking/Stop) and F-004 (peer jobs in the Fleet view).
