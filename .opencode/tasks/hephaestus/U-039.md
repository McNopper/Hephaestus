User report 2026-09-20 after an Eclipse restart: "why is the last chat not default anymore, also the last model is not default anymore." A fresh chat session falls back to the repo default model from opencode.json (currently kimi-code-plan-global/k3-256k) and a fresh/empty session instead of resuming where the user left off. Expected: on restart the chat reopens the most recent session (or offers it one click away) and preselects the last deliberately-chosen model (per the selector's deliberate-commit rule: only an opened-dropdown pick or Enter sets it - and THAT choice should persist).
