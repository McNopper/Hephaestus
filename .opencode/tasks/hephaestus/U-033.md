User report 2026-09-19: making the board pane larger scales only the right columns; should be equal.

Fix pointer: createColumn sets 'new GridData(GridData.FILL_BOTH)' - the style-only constructor sets alignment but NOT grabExcessHorizontalSpace, so extra space is not taken evenly; use 'new GridData(SWT.FILL, SWT.FILL, true, true)'. Same audit for the V arms' parent (pipelineScroll expand flags) so the two arms share growth instead of trailing whitespace.
