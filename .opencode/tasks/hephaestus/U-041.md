User direction 2026-09-20: "like opencode v2, independent if chat or from the fleet, i want to see subagents and console tasks." The v2 TUI shows subagents and subprocesses; Eclipse shows neither (roadmap open item, previously unticketed). v2 surfaces: session parentID nesting (subagents), /api/shell + /api/pty endpoints and shell.* events (console tasks). Scope: (1) the session model carries parent/children so subagent sessions nest under their parent in Session Details, the Server view, and the Fleet tree (when it lands); (2) every shell/PTY process a session spawns is listed with status + output tail, live while running, opened in a real Eclipse console (MessageConsole via the AgentToolsConsole pattern) - not a custom text dialog; (3) shell.* event wiring over the existing event stream; (4) works identically for chat sessions (primary client) and fleet worker sessions (the fleet server connection / daemon read-through, see U-024). Read-only first slice: interactive PTY input deferred (TM Terminal evaluation is a follow-up, see docs/fleet-observability-eclipse-reuse.md).
