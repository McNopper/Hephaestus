Follow-up from U-085: jacoco's report mojo has NO classes/sources override (descriptor-verified:
report params = dataFile, excludes, includes, title, formats, outputDirectory, ...), and per-module
verify runs BEFORE the tests module builds - so a production bundle can neither point its report at
the tests module's exec (reactor order) nor be covered by its own (no tests). The exec files DO carry
full-run instrumentation of production classes; only the HTML rendering of that fact is missing.
Research options and implement the winner:
- report-aggregate (descriptor-verified params: reactorProjects, includeCurrentProject, dataFileIncludes/Excludes)
  in a late module, with explicit pom dependencies on the bundles
- a releng script that runs the jacoco report goal at reactor end with merged execs
- dataFileIncludes globbing across tests-module execs
