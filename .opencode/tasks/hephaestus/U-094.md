Surfaced during U-091 PIT hardening while building fixtures: planSprint with an EXPLICIT
sprint id does not bump the meta counter, while auto-minted sprint ids do. Consequence:
mixing explicit and auto ids can mint an id that collides with an existing explicit one
(the counter never learned about the explicit id). Verify the behavior live, decide the
fix (explicit ids should also advance the counter), add a store test pinning it.
