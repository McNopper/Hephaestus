Reported live 2026-10-07: 'the feature is missing, that i can send here something to the background'. It exists but is invisible: POST /session/{id}/background is adopted (U-042) and ChatView has a plain-text 'Background' action on the view toolbar (ChatView.java:677-693) with no icon and no keybinding, while the tooltip names the TUI's Ctrl+B. Close the parity gap: (1) a real keybinding - Ctrl+B scoped to the chat view (a chat-specific binding context so Build All keeps working elsewhere), mirroring the AbortChatHandler/NewChatHandler command+handler pattern; (2) a visible composer affordance (button next to Stop in the input row); (3) after backgrounding, the notice points at the Background view. Chat bundle only.
