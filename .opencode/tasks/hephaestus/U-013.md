- **Kind:** backlog ticket for developers implementing session todo display.
- **Related:** the root ROADMAP's v2 todo-source investigation and session observability work.

TUI parity goal: display the agent's session todo state. The v2 API has no session-todo endpoint or todo field on the session resource, verified against the live 2.0.11 contract on 2026-09-21. The retired client endpoint and its unused fleet import have been removed. Establish the v2 data source first; transcript tool outputs are a candidate to investigate, not an established contract. Task-store todos are independent and remain supported.
