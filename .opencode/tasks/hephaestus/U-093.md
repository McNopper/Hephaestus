Owner 2026-10-12: improve icons/emojis in the Server panel - colored emojis for a more
fancy, less static look, and rows that SAY what is happening (a lot happens in the
background but the view looks static).

Design direction (SWT native tree renders color emoji on Windows via Segoe UI Emoji):
1. State glyphs in session row labels: busy/working = colored dot or bolt, failed = red,
   idle = quiet (avoid noise); agent rows with running work get a robot/working glyph.
2. Details column becomes LIVE: for busy sessions show the current tool/activity
   (ActivityTracker/SessionObserver already know 'running bash: git status'), plus
   cost/token counters that tick while a session works.
3. Category labels speak: 'Sessions (3, 1 working)' style counts (partially exists -
   keep consistent).

Implementation home: ServerLabels (pure, SWT-free, unit-tested) + ServerView label
providers; live refresh rides the existing busy-set/SSE update paths.
Related queued work: U-092 (steer running subagents) - both need a wave (S-10).
