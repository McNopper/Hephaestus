User vision 2026-09-18 (the Hephaestus principle): fully autonomous fleets and waves - every stage executed by its relevant agent; an agent needing clarification passes the ticket back, the ORIGINATOR agent clarifies; only when no agent can resolve it does the user act. With U-021 (auto-accept+advance) and U-022 (recurring waves + NEEDS-HUMAN) this completes the autonomy contract: create-clarify-build-verify-review-advance, humans as last resort.

Implementation pointers: the store already records send-backs with reasons and STALE invalidation on upstream change (inputs changed markers) - the missing piece is ROUTING: on a clarification-prefixed send-back, find the originator ticket (upstream stage via StageReadiness.upstreamStage + epic chain, else requirements, else human), clear ITS blocker if any, and let the wave loop dispatch it with the question in the prompt. The round-trip counter can ride the ticket history (count clarification send-backs between the same stage pair since the last artifact change).
