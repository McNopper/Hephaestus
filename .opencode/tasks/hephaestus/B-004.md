Live-found 2026-09-17 while re-dispatching U-011 (after the 2026-09-16 timeout failure):

1. LEAKED SERVE: yesterday's timed-out run left its spawned opencode serve --port 62090 alive (pid verified via Win32_Process). The orphan held locks in the fleet worktree, so leet_reset failed with git worktree remove --force ... Permission denied (exit 255), aborting before branch cleanup - which then made the next dispatch fail with Branch opencode/U-011 already exists.
2. STALE ENDPOINT: after the orphan was killed, the still-running engine tried to reuse its recorded endpoint (port 62090) and failed with Cannot reach opencode server at http://127.0.0.1:62090 (POST /session...) for EVERY later dispatch - only a full daemon restart fixed it. The engine never re-probed nor respawned.

Recovery performed manually: kill leaked pid, git worktree remove --force + git branch -D opencode/U-011, unblock ticket, daemon shutdown (hello then daemon/shutdown on one connection) + leet-daemon.ps1 restart. The engine should do each of these itself.
