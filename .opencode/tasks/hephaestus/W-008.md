**THE EDITING TRANSITIONS (self-contained — do NOT read DESIGN.md):**

| Key | Mode | Effect |
|---|---|---|
| any single printable char (length 1, not a special key) | INSERT | insert at cursor; col+1 |
| `"Enter"` | INSERT | split the line at cursor; cursor to new line, col=0 |
| `"Backspace"` | INSERT | col>0: delete char left of cursor, col-1. col==0 && line>0: join with previous line (cursor at join point) |
| `"Delete"` | INSERT | col<line length: delete char right of cursor. col==line length && line<last: join next line onto this one |
| `"x"` | NORMAL | delete char at cursor (if line non-empty); col clamps |
| `"d"` | NORMAL | delete the entire current line (if it leaves >= 1 line; an empty buffer keeps one empty line); cursor clamps |
| `"u"` | NORMAL | pop the newest snapshot from undoStack, restore it as the state |

**Undo protocol:** before EVERY state-changing transition (the ones above +
mode changes from chunk 2 are NOT undoable; only buffer edits are), push a
full deep-copy snapshot of the pre-edit state onto `undoStack` (append;
if length would exceed 100, drop the OLDEST). `"u"` pops the LAST snapshot
and restores it — the restore itself does not push a new snapshot.
