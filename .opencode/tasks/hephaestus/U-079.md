Harness layer of the V-enforcement contract: the dispatch prompt DELIVERS the upstream automatically,
so an agent working concrete detail never loses the architecture.

- New UPSTREAM DEFINITIONS section: epic-chain tickets in the governing stages (upstreamStage ladder) with their
  recorded artifact refs - only refs that exist, deduped, capped for determinism.
- GOVERNING DEFINITION MISSING block when a governing done/in-review ticket has zero artifacts:
  'do not implement bare - produce/link the definition first or task_send_back to that stage'.
- Non-bug staged ticket with no governing definition at all: top-down backfill instruction (write the abstraction
  first, record it, then continue). type=bug exempt - bare bugfixes are legitimate.
- PIPELINE PROTOCOL additions: coverage requirement (cite upstream ids), 'you claim in-review, the gate declares
  done', 'works is proven on the paired test-* stage'.
- Two-trigger send-back wording stays exactly as the contract defines it (missing / refactor-or-clarify).
