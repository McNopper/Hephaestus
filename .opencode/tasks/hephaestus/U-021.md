User direction 2026-09-18: the end user normally has NOTHING to do except blocked elements. Acceptance is the first gate to automate: reviewer agent (cross-vendor principle: prefer a different model family than the executors) judges settle->done/advance or send-back. Implementation pointers: TaskFleet/FleetRunner settle path already records artifacts + merges; dispatch a second session with the reviewer prompt (RoleAgents maps roles->agents; add 'reviewer'); on its completion call task advance/sendBack through the store. Auto-dispatch's existing loop drains the advanced next-stage ticket - with this ticket, the V pipeline becomes self-driving per stage.
