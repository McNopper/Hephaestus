Rule 7 of the V-enforcement contract: the right leg is a ladder (unit proves implementation, component
proves design, library proves architecture, integration proves system, acceptance proves requirements)
and a failed validation loops back HORIZONTALLY to the definition that produced it - only a missing or
wrong definition loops VERTICALLY. The store (reportHorizontal, U-031) and the pump (ResolutionPolicy)
already have both routes; agents have only the vertical one.

Gaps to close:
- TaskToolProvider: expose task_report_horizontal (project, ticket_id, reason, by) mirroring
  TaskStore.reportHorizontal (pair stage, blocked, 'reported from ...').
- SelfClaimPrompt: teach the routing - validation failure against the pair -> task_report_horizontal;
  missing/wrong upstream or own-stage defect -> task_send_back (previous); questions -> 'clarification:'.
- TaskFleet review FAIL: route by stage kind - verification stage -> reportHorizontal (pair),
  definition stage -> sendBack (previous). ReviewPrompt stays read-only; the engine applies the verdict.
