```java
public class EditorCoreTest {
    static int passed = 0, failed = 0;

    /** One vector: from a start state, apply keys, compare the JSON of the result. */
    static void check(String name, String startJson, String[] keys, String expectJson) {
        EditorCore.CoreState s = EditorCore.fromJson(startJson);
        for (String k : keys) s = EditorCore.apply(s, k);
        String got = EditorCore.toJson(s);
        if (got.equals(expectJson)) { passed++; System.out.println("PASS " + name); }
        else { failed++; System.out.println("FAIL " + name + "\n  got:    " + got + "\n  expect: " + expectJson); }
    }

    public static void main(String[] args) {
        // your vectors here - use the table below
        System.out.println(passed + " passed, " + failed + " failed");
        if (failed > 0) System.exit(1);
    }
}
```

**Vector table (15 required — write the expected JSON by hand; the state
grammar is `{"lines":[...],"cursor":{"line":L,"col":C},"mode":"...","undoStack":[...]}`):**

Start from `initial()` = `{"lines":[""],"cursor":{"line":0,"col":0},"mode":"NORMAL","undoStack":[]}`
for the first vector of each group, chain subsequent vectors from the
previous result where noted.

1. `Right` on empty buffer: no-op (col 0 clamps to line length 0)
2. `i` then type `"a"`: lines `["a"]`, col 1, mode INSERT, undoStack has 1 snapshot (the pre-insert state)
3. Type `"hello"` (5 keys after `i`): lines `["hello"]`, col 5
4. `Enter` after typing `"he"` then `"llo"` then `Enter`: lines `["hel","lo"]`, cursor line 1 col 0
5. `Backspace` at col 0 of line 1 (after vector 4): lines join back to `["hello"]`, cursor at the join point
6. `Escape` then `End`: mode NORMAL, col at end
7. `Down` on single-line buffer: no-op (line clamps)
8. `PageDown` on 3-line buffer: clamps to last line
9. `Ctrl+End`: line last, col that line's length
10. `x` in NORMAL on `"hello"` with cursor at 0: lines `["ello"]`
11. `d` on 2-line buffer: deletes current line, 1 line remains
12. `u` after a `d`: restores the pre-delete state exactly (including undoStack minus the restored snapshot)
13. `Delete` at end of line 0 of 2 lines: joins line 1 onto line 0
14. `Home` after `End`: col 0
15. `Left` at 0,0: no-op
