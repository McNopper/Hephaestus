User direction 2026-09-15: "Board and Fleet should also have better icons." Today every other surface has dedicated artwork - the shared ui bundle (com.opencode.ide.ui/src/main/resources/icons/) ships agent.png, model.png, session.png, server.png, mcp.png, skill.png plus a full provider logo set (16/32px + SVG sources) - but there is no board or fleet icon at all, so those two flagship views fall back to the generic Eclipse view icon. Scope: design/produce dedicated view icons for the Board (kanban/task-board motif) and Fleet (worktree/runner motif) in the existing icon style, wire them into the view descriptors. Optional follow-up (only if cheap and consistent): distinct small state icons for fleet job states (RUNNING/COMPLETED/MERGED/FAILED) and board column headers, reusing the new visual language.
