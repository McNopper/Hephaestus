User report 2026-09-15 (live): five tickets dispatched from a chat session via the fleet MCP server (fleet_fleet_dispatch) do not appear in the Eclipse Fleet view. Architecture cause: FleetControl is per-process - the stdio MCP server (FleetStdioMain) owns its engine in the chat's server process, the Fleet view drives its own in Eclipse; jobs() (TaskFleet.java:511) is engine-local, so peer-engine jobs are invisible. Full fix is V-006 (daemonized engine + attach). This ticket is the interim read-only visibility: reconstruct the job list from the shared on-disk truth both engines already maintain - task-store claim markers and .git/opencode-fleet/<ticket> worktrees (TaskFleet already reconciles these on engine start, DispatchGuard already serializes cross-engine via markers) - so the operator sees ALL fleet activity in one view today, not just Eclipse-launched jobs.
