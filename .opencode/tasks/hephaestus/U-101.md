Live finding while verifying the Eclipse chat panel (2026-10-23): the chat-web Markdown pipeline renders basic Mermaid (flowchart with plain [nodes], simple ASCII labels, --> edges; sequenceDiagram with participant-as, ->> messages, self-messages) but breaks on subgraph blocks, cylinder/shape-decorated nodes, <br/> in labels and aliases with spaces/slashes - valid Mermaid elsewhere shows as raw or broken output. The bundled TUI renders the full Mermaid surface (upstream even fixed Mermaid-in-labels rendering recently). Align the panel's mermaid.js version/config with the TUI's, or document the supported subset in docs and keep answers within it.
