**Transitions to implement (the complete cursor+mode table):**

| Key | Mode | Effect |
|---|---|---|
| `"Up"` | any | cursor line-1 (clamp 0); col clamps to new line's length |
| `"Down"` | any | cursor line+1 (clamp last); col clamps to new line's length |
| `"Left"` | any | cursor col-1 (clamp 0); if col already 0 and line>0: line-1, col=end of that line |
| `"Right"` | any | cursor col+1 (clamp to line length); if col already at end and line<last: line+1, col=0 |
| `"Home"` | any | col=0 |
| `"End"` | any | col=line length |
| `"Ctrl+Home"` | any | line=0, col=0 |
| `"Ctrl+End"` | any | line=last, col=that line's length |
| `"PageUp"` | any | line-12 (clamp 0); col clamps |
| `"PageDown"` | any | line+12 (clamp last); col clamps |
| `"i"` or `"Insert"` | NORMAL | mode=INSERT |
| `"Escape"` | INSERT | mode=NORMAL |

All other keys in NORMAL mode: no-op (return `s` unchanged).
Never mutates the input state — build a new CoreState (reuse the lines array
is OK because strings are immutable).
