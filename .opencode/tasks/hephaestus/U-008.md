User report 2026-09-16: "when going with the mouse over the selection panel above the chat, the model is often changed too easily." Windows read-only SWT combos fire SWT.Selection on mouse-wheel, so scrolling the transcript with the pointer over the agent/model/variant row silently flipped the next-send model. Fixed at the source (not via provider whitelisting, which was removed again): SelectorGuard commits only armed picks.
