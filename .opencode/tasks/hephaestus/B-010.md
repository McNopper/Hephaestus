Live-found 2026-09-20 by the U-026 fleet worker (ses_f40384bcdffe8suE0t1CTmbJMS, 33+ messages): the merge-back AC-path gate (TaskFleet.enforceAcPaths) extracts expected file paths from acceptance criteria via regex - and AC text containing 'e.g.' parses as a bogus path 'e.g', so tickets whose ACs use 'e.g.' fail or skew the gate. The gate's path extraction must (a) only accept tokens that look like real repo paths (contain a path separator or a known extension), (b) never derive paths from natural-language abbreviations (e.g., i.e., etc.), and (c) be pinned by tests with AC texts drawn from real tickets (B-007's ACs are a fixture: they contain 'e.g.'). Found while judging the U-026 flow-trace requirements - the same gate B-007's stage-aware matrix will replace the expectations of; until then the regex must stop misfiring.
